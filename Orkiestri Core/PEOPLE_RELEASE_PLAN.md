# 1. PURPOSE

This document defines the release strategy for People Hub.

The objective is to establish:

- Product scope.
- Release phases.
- MVP definition.
- Future roadmap.
- Validation criteria.

---

# 2. PRODUCT POSITIONING

People Hub is an enterprise Human Capital Management module inside Orkiestri.

It combines:

Human Resources Management

+

Personnel Administration

+

Workflow Automation

+

Artificial Intelligence

---

# 3. VERSION STRATEGY

Initial releases:

People Hub v1.0

Foundation Release

People Hub v1.5

Process Automation Release

People Hub v2.0

AI Intelligence Release

Time tracking
