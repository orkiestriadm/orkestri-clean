# Main Product

## Orkiestri Hub

Orkiestri Hub is a modular enterprise platform.

Instead of delivering one large ERP, the platform is composed of independent products that share the same ecosystem.

Each product can operate independently while remaining fully integrated with every other product.

# Product Vision

# Current Architecture

Architecture Style:

Modular Monolith

Prepared for future Microservices migration.

Communication between modules must occur through well-defined services and events.

Direct coupling between products is discouraged.
