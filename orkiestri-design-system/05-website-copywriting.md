# Objetivo

Definir toda a comunicação do website da Orkiestri.

A linguagem deve transmitir:

• Tecnologia
• Elegância
• Confiança
• Simplicidade
• Inovação

Nunca utilizar linguagem exageradamente comercial.

Nunca utilizar frases como:

"O melhor sistema."

"A solução definitiva."

"A empresa número 1."

Preferir uma comunicação semelhante a:

Apple

Stripe

Linear

Vercel

Notion

Framer

Microsoft

# REGRAS DE COPY

Escreva para decisores.

Venda transformação.

Venda resultados.

Venda crescimento.

Nunca venda funcionalidades.

Sempre explique benefícios.

Evite textos longos.

Use frases curtas.

Cada seção deve responder uma pergunta do visitante.

Toda página deve terminar com uma chamada para ação.

A comunicação deve reforçar que a Orkiestri é uma empresa de tecnologia de alto nível, e que o Orkiestri One é a plataforma que conecta toda a operação do cliente.
