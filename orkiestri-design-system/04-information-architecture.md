# ORKIESTRI
## Information Architecture
Version: 2.0

---

# Objetivo

Este documento define toda a arquitetura de informação do website da Orkiestri.

Seu objetivo é garantir que a navegação seja simples, intuitiva e focada em conversão, posicionando a Orkiestri como uma Enterprise Software Company.

O website deve transmitir credibilidade, inovação e sofisticação.

O visitante deve compreender em menos de 10 segundos:

• Quem somos

• O que fazemos

• Qual problema resolvemos

• Como podemos ajudá-lo

---

# Objetivos do Website

Posicionar a Orkiestri como Software Factory.

Apresentar o Orkiestri One.

Apresentar os módulos.

Apresentar os serviços.

Gerar leads.

Fortalecer a marca.

Melhorar SEO.

Atrair empresas de médio e grande porte.

# Conclusão

O website da Orkiestri deve ser percebido como o website de uma empresa global de tecnologia.

A experiência deve transmitir simplicidade, sofisticação e confiança.

Cada página deve existir com um propósito claro.

Cada interação deve aproximar o visitante da conversão.

Mais do que um website, o resultado final deve ser uma plataforma institucional preparada para acompanhar a evolução da empresa pelos próximos anos.
