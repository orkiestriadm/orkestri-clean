# Project Phoenix

> Complete redesign of the Orkiestri digital ecosystem.

Version 1.0

---

# Overview

Project Phoenix is the complete reconstruction of the Orkiestri institutional website.

This is not a redesign.

This project transforms Orkiestri from a software product into an Enterprise Software Company.

The website will become the company's primary commercial platform and will represent its brand, products, services and engineering quality.

---

# Project Goals

• Reposition the Orkiestri brand

• Present Orkiestri as a Software Factory

• Launch the Orkiestri One platform

• Present all products

• Present all services

• Increase perceived value

• Generate qualified leads

• Improve SEO

• Build a scalable codebase

# Definition of Success

The final website must look like the digital presence of a global software company.
