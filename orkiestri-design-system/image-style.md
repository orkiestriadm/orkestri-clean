# IMAGE STYLE GUIDE - ORKIESTRI
@skill ui-ux-pro-max

## Objective
Generate all product images using a single premium visual language inspired by Apple and Tesla.

## Rules
- Ultra realistic.
- Premium enterprise software aesthetic.
- Clean, modern and minimalist.
- Sharp details.
- High contrast.
- Soft cinematic lighting.
- Consistent color palette with Orkiestri branding.
- Plenty of negative space.
- No visual noise.
- No stock photo appearance.
- No generic business people.
- Technology-first composition.

## Composition
- 16:9
- Central focal point.
- Balanced layout.
- Professional perspective.
- Background with subtle gradients and depth.
- Glassmorphism allowed.
- Soft reflections allowed.
- Premium shadows.

## Product Representation
Represent concepts visually instead of showing software screenshots.

Examples:
- AI
- Automation
- Cloud
- Infrastructure
- Analytics
- Cybersecurity
- Fleet
- Service Desk
- Monitoring
- CRM
- Finance
- Workflow
- Integration

## Card Style
Every image must be presented inside a premium card.

Card:
- Rounded corners (20-24px)
- Thin border (#FFFFFF14)
- Soft shadow
- Frosted glass effect
- Premium spacing

## Hover Animation
Prepare image for CSS hover.

Expected behavior:
- scale(1.04)
- translateY(-4px)
- transition 250ms ease
- stronger shadow on hover
- no aggressive zoom

## Quality
- 4K
- HDR
- Ultra sharp
- Noise free
- High definition
- Professional rendering
- Consistent lighting
- Consistent perspective

## Forbidden
- Low quality
- Cartoon
- Clipart
- Flat illustration
- Busy backgrounds
- Random colors
- Text inside image
- Logos
- Watermarks
- Fake UI screenshots
